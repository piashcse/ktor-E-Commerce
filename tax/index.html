    Tax Engine

    Tax zones, classes, rules and exemptions resolved per order line.

    Resolution order

    1. Customer/business exemption (active, matching country or global, not expired) → zero tax.
    2. A matching tax_zone with isNexus = false → zero tax.
    3. The most specific active rule for the destination country:
    4. zone-scoped beats country-wide
    5. class-scoped beats class-agnostic
    6. category-scoped beats category-agnostic
    7. then highest priority, then oldest rule.
    8. The assigned product tax class default rate/mode.
    9. Application default (TAX_DEFAULT_RATE, default 5%).

    A rule is only eligible when its zone/class/category (when set) matches the line.

    Inclusive vs exclusive

    • Exclusive (default): the line amount is net; tax is added to the order total.
    • Inclusive: the line amount is gross; tax is carved out (net = gross / (1 + rate)). The order total does not add inclusive tax again.

    Tax rule body

    {
  "country": "BD",
  "categoryId": "category-uuid",
  "zoneId": "zone-uuid",
  "taxClassId": "class-uuid",
  "rate": 0.15,
  "isInclusive": true,
  "priority": 10,
  "isActive": true
}

    Tax class body

    { "name": "Reduced", "code": "REDUCED", "rate": 0.10, "isInclusive": true, "isActive": true }

    Tax zone body

    { "name": "Dhaka", "country": "BD", "region": "Dhaka", "isNexus": true, "priority": 10, "isActive": true }

    Exemption body

    {
  "userId": "user-uuid",
  "businessTaxId": "BIN-123",
  "country": "BD",
  "reason": "Reseller certificate",
  "certificateUrl": "https://example.com/cert.pdf",
  "expiresAt": "2027-01-01T00:00:00"
}

    At least one of userId or businessTaxId is required. A null country applies to every destination. Checkout accepts businessTaxId and stores it with taxExempt on the order.

    Per-line breakdown

    GET /api/v1/checkout/summary (and order responses) expose:

    • order_item.taxRate, taxInclusive, taxClassId, taxAmount
    • taxLines[] with productId, taxClassId, rate, inclusive, netAmount, taxAmount, grossAmount

    Tax is calculated on the post-discount item total and snapshotted on the order line.
