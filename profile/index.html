    User Profile

    Manage the authenticated user's account profile details and avatar image.

    Authentication

    All endpoints in the Profile module require a valid Bearer JWT access token passed in the Authorization header:

    Authorization: Bearer <your_access_token>

    Profile Endpoints Overview

    Method Endpoint Description Auth Required
    GET /api/v1/profile Retrieve user profile information Bearer JWT
    PUT /api/v1/profile Update user profile information Bearer JWT
    POST /api/v1/profile/image-upload Upload profile image (multipart) Bearer JWT

    Endpoint Details

    1. Get User Profile

    GET /api/v1/profile Bearer Token Required

    Retrieves the currently authenticated user's complete profile record.

    Headers

    Header Value Required Description
    Authorization Bearer <access_token> Required Valid user access token
    Accept application/json Optional Expected response format

    Request Examples

    curl -X GET 'http://localhost:8080/api/v1/profile' \
  -H 'Accept: application/json' \
  -H 'Authorization: Bearer eyJhbGciOiJIUzUxMiIsInR5cCI6IkpXVCJ9...'

    val response = client.get("http://localhost:8080/api/v1/profile") {
    header(HttpHeaders.Authorization, "Bearer $accessToken")
    accept(ContentType.Application.Json)
}
val profile: UserProfile = response.body()

    const response = await fetch("http://localhost:8080/api/v1/profile", {
  headers: {
    "Accept": "application/json",
    "Authorization": `Bearer ${accessToken}`
  }
});
const profile = await response.json();

    2. Update User Profile

    PUT /api/v1/profile Bearer Token Required

    Updates profile information for the authenticated account.

    Query / Form Parameters

    Parameter Type Required Description
    firstName string Optional User's given name
    lastName string Optional User's family name
    mobile string Optional User's mobile phone number
    faxNumber string Optional User's fax contact number
    streetAddress string Optional Street address line
    city string Optional City or municipality
    postCode string Optional Postal / ZIP code
    gender string Optional Gender identity (Male, Female, Other)

    Headers

    Header Value Required Description
    Authorization Bearer <access_token> Required Valid user access token

    Request Examples

    curl -X PUT 'http://localhost:8080/api/v1/profile?firstName=Mehedi&lastName=Hassan&mobile=01812353930&streetAddress=Dhaka&city=Dhaka&postCode=1205&gender=Male' \
  -H 'Accept: application/json' \
  -H 'Authorization: Bearer eyJhbGciOiJIUzUxMiIsInR5cCI6IkpXVCJ9...'

    val response = client.put("http://localhost:8080/api/v1/profile") {
    header(HttpHeaders.Authorization, "Bearer $accessToken")
    parameter("firstName", "Mehedi")
    parameter("lastName", "Hassan")
    parameter("mobile", "01812353930")
    parameter("city", "Dhaka")
    parameter("postCode", "1205")
    parameter("gender", "Male")
}
val updatedProfile: UserProfile = response.body()

    3. Upload Profile Image

    POST /api/v1/profile/image-upload Bearer Token Required

    Uploads a new avatar image for the authenticated user.

    Multipart Form Data

    Field Type Required Description
    image binary file Required Supported formats: image/jpeg, image/png, image/webp (.jpg, .jpeg, .png, .webp). Maximum size: 5 MB.

    Headers

    Header Value Required Description
    Authorization Bearer <access_token> Required Valid user access token
    Content-Type multipart/form-data Required Multipart boundary header

    Request Examples

    curl -X POST 'http://localhost:8080/api/v1/profile/image-upload' \
  -H 'Authorization: Bearer <access_token>' \
  -H 'Content-Type: multipart/form-data' \
  -F 'image=@profile.jpg;type=image/jpeg'

    val response = client.submitFormWithBinaryData(
    url = "http://localhost:8080/api/v1/profile/image-upload",
    formData = formData {
        append("image", fileBytes, Headers.build {
            append(HttpHeaders.ContentType, "image/jpeg")
            append(HttpHeaders.ContentDisposition, "filename=\"profile.jpg\"")
        })
    }
) {
    header(HttpHeaders.Authorization, "Bearer $accessToken")
}
val uploadedUrl: String = response.body()

    Response

    {
  "message": "File size exceeds the 5MB limit or invalid image type"
